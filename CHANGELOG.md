## [1.0.2] - 2026-04-28

### Changed
- Refactored repository code for improved readability and consistency
- Improved type hints across repository and query components
- Streamlined repository method calls

---

## [1.0.1] - 2026-04-27

### Fixed
- Repository cache invalidation bug
- Memory leak in query iterator
- Improved query builder consistency

---

## [1.0.0] - 2026-04-20

### Added
- Initial release of the CQRS package
- Command and query buses
- Repository abstractions with caching support
- Transaction management utilities
- Domain event dispatching
- Automatic handler discovery via PHP attributes
- Symfony Serializer and PropertyAccess integration
- Documentation and usage examples
